# v0.4.1 Founding Record

## Timeline

**v0.3 (GREEN):** 19 missions. Built Pidgin as a working CLI package with MLD
pipeline, batch dispatch, per-repo nests, 8 verbs, adaptive stopping, draft
stratification, import tracking, idempotency, bidirectional MLD (UNLOCK at 4/5).

**v0.4 (KILLED at M6):** Started in fe-toolkit. M1-M5 GREEN (incremental writes,
graceful shutdown, progress tracking, class method extraction, gate model switch
from haiku to gpt-4.1-mini). M6 failed on context window exhaustion during batch
polling. Sprint paused for convergence investigation.

**Convergence discovery:** The convergence test used by `pidgin index` was wrong.
`geometry.py:antipode_test()` counted vectors above mean cosine similarity — not
the antipode reflection test the operator designed. The real test existed in
`mld.py:_antipode_convergence()` but was only used in the single-function path.
Two code paths, two different tests, neither was correct.

**Calibration experiment:** 12,600 API calls (126 functions × 25 calls × 4
temperatures), 37,638 embedded vectors. Key findings:

- Draft 3 has HIGHER variance than draft 1 (token compression scatters, doesn't converge)
- Temperature 0.3 is 2.7x tighter than temperature 1.5
- Pooling drafts or temperatures hurts convergence
- Spherical variance < 0.10 gives 81% convergence at N=25
- N=10 is sufficient (mean deviation 0.0095 from N=25 reference)
- Body length correlation with sv is weak (0.169) — semantic clarity matters, not size

**Convergence rewrite:** Patch P1 replaced antipode_test with spherical_variance
and convergence_verdict. But convergence_verdict uses draft decay (sv1 > sv2 > sv3)
which the calibration data proved wrong. The pipeline still reports near-0%
convergence because draft_3 always has higher variance than draft_1.

**Migration:** Pidgin extracted to its own repo (github.com/wiregrassio/pidgin).
Src layout. Sprint history moved. Fe-toolkit stripped of all Pidgin code.

**Calibration loading:** 126 functions loaded from calibration data into the nest
using the correct test (sv < 0.10 on draft_1 at t=0.3). 102 CONVERGED, 19
AMBIGUOUS, 5 DIVERGENT. All queryable. Zero API calls.
