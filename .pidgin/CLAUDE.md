# .pidgin/

This directory is the Pidgin nest for this repository.

- `nest/` — ChromaDB persistent store. Function descriptions, module
  summaries, behavioural contracts. Generated by `pidgin index`.
- `CLAUDE.md` — this file. Tells agents how to query the nest.

## Querying

```
pidgin query "what handles retry"
```

Returns the highest-similarity function descriptions from the nest.
The query is embedded with text-embedding-3-small @ 256 dim and
matched by cosine similarity.

## Re-Indexing

```
pidgin index . --write-db
```

Re-runs the MLD pipeline against current source. Existing nest entries
are upserted by file path + function name.

## Provenance

This file is auto-generated by `pidgin index`. Edit freely; the
generator will not overwrite an existing file.
